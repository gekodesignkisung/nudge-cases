# nudge-cases

**환경은 프로그램인가** — 명령하지 않고 행동을 바꾼 환경 9개 사례.

환경은 사람에게 직접 명령하지 않는다. 대신 어떤 행동은 쉽게, 어떤 행동은 어렵게 만들면서
선택의 방향을 바꾼다. 이 사이트는 그 사례 9개를 다이어그램과 수치로 정리한
**한 화면에 한 섹션** 형식의 덱이다.

## 조작

| 동작 | 키 |
|------|-----|
| 다음 | `→` `↓` `Space` `PageDown` |
| 이전 | `←` `↑` `PageUp` |
| 처음 / 끝 | `Home` / `End` |

상단 헤더의 섹션 메뉴, 우측 이전·다음 버튼, 하단 점으로도 이동한다.
스크롤 스냅이라 마우스 휠과 터치 스와이프도 한 장씩 넘어간다.

총 13장 — 표지, 좌표계(산점도), 사례 9장, 종합, 주석.

## 사례

| # | 사례 | 범주 | 핵심 수치 |
|---|------|------|-----------|
| 1 | 장기기증 기본값 | 제도 | 오스트리아 99%+ vs 독일 12%, 등록률 약 6배 |
| 2 | 구글 → 애플 기본 검색엔진 | 웹 기본값 | 2022년 $20B, 변경은 3탭 |
| 3 | 스히폴 공항 소변기의 파리 | 제품 형태 | 흘림 −80% (원 연구 없음) |
| 4 | 캠든 벤치 | 물리 공간 | 제거된 행동 5종, 표지판 0장 |
| 5 | 욕망의 길 | 물리 공간 · 역방향 | 사람이 환경을 고쳐 쓴 경우 |
| 6 | 개방형 사무실 | 사무실 배치 | 대면 −70%, 이메일 +56% |
| 7 | r/assholedesign | 대항 기록 | 게시물 1,002개가 연구 데이터로 |
| 8 | 추천 · 자동재생 | 알고리즘 | 유튜브 70%, 넷플릭스 80% |
| 9 | 회의 없는 날 | 조직 규칙 | 76개 기업, 생산성 +35%, 스트레스 −26% |

## 구성상의 판단

- **반증을 숨기지 않았다.** 장기기증과 스히폴은 넛지 담론의 대표 사례지만 각각
  종단 연구로 반박되거나 원 수치가 검증된 적이 없다. 주황 세로선으로 표시했다.
- **역방향 사례를 포함했다.** 욕망의 길과 r/assholedesign은 사람이 환경을 바꾼 경우다.
  "환경이 사람을 프로그래밍한다"는 명제의 반례로 넣었다.
- **출처를 1차/2차/참고로 구분했다.** 원논문·공식 자료·당사자 인터뷰는 `1차`,
  언론 보도와 비평은 `2차`, 해설과 백과는 `참고`로 태그를 달았다.
- **규제 사례는 뺐다.** FTC Click-to-Cancel 룰이 2025년 7월 무효화되어,
  카드가 스스로를 반박하며 메시지를 잃었다.


## 보기

빌드 과정이 없다. `index.html` 하나로 완결된다.

```bash
# 바로 열기
start index.html          # Windows
open index.html           # macOS

# 또는 로컬 서버
python -m http.server 8000
```

## GitHub Pages 배포 (현재 비활성)

저장소가 프라이빗이라 Pages를 쓸 수 없어 자동 트리거를 꺼두었다.
워크플로 파일(`.github/workflows/pages.yml`)은 그대로 남아 있다.

공개로 전환해 배포하려면:

1. **Settings → General → Danger Zone** 에서 저장소를 public으로 변경
2. **Settings → Pages → Build and deployment → Source** 를 **GitHub Actions** 로 설정
3. `pages.yml`의 주석 처리된 `push:` 블록을 복원

이후 `main` 푸시마다 `https://gekodesignkisung.github.io/nudge-cases/` 로 배포된다.
(유료 플랜이면 프라이빗 상태로도 Pages를 켤 수 있다.)

## 기술

- 의존성 없음. 외부 스크립트 없음. `index.html` 단일 파일.
- 다이어그램 10개 전부 손으로 쓴 인라인 SVG (`currentColor` 기반이라 테마를 따라간다)
- 화면 전환은 CSS `scroll-snap` + `IntersectionObserver`. 애니메이션 라이브러리 없음.
- 라이트/다크 양쪽 지원 — `prefers-color-scheme` + `data-theme` 속성
- 폰트: Bricolage Grotesque, IBM Plex Sans KR, IBM Plex Mono (Google Fonts)

세로 공간이 부족한 경우(좁은 화면, 낮은 뷰포트)에는 해당 장 안에서만 스크롤되고,
장 사이 이동은 그대로 한 장씩 유지된다.
