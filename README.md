# nudge-cases

**환경은 프로그램인가** — 명령하지 않고 행동을 바꾼 환경 10개 사례.

환경은 사람에게 직접 명령하지 않는다. 대신 어떤 행동은 쉽게, 어떤 행동은 어렵게 만들면서
선택의 방향을 바꾼다. 이 사이트는 그 사례 10개를 직접 만져 보는 다이어그램과 수치로 정리한
**한 화면에 한 섹션** 형식의 덱이다.

## 조작

| 동작 | 키 |
|------|-----|
| 다음 | `→` `↓` `Space` `PageDown` |
| 이전 | `←` `↑` `PageUp` |
| 처음 / 끝 | `Home` / `End` |

상단 헤더의 섹션 메뉴, 우측 이전·다음 버튼, 하단 점으로도 이동한다.
스크롤 스냅이라 마우스 휠과 터치 스와이프도 한 장씩 넘어간다.

총 14장 — 표지, 좌표계(산점도), 사례 10장, 종합, 주석.

## 사례

| # | 사례 | 범주 | 핵심 수치 |
|---|------|------|-----------|
| 1 | 장기기증 기본값 | 제도 | 오스트리아 99.98% vs 독일 12% |
| 2 | 구글 → 애플 기본 검색엔진 | 웹 기본값 | 2022년 $20B, 변경은 3탭 |
| 3 | 스히폴 공항 소변기의 파리 | 제품 형태 | 흘림 −80% (원 연구 없음) |
| 4 | 캠든 벤치 | 물리 공간 | 제거된 행동 5종, 표지판 0장 |
| 5 | 개방형 사무실 | 사무실 배치 | 대면 −70%, 이메일 +56% |
| 6 | 추천 · 자동재생 | 알고리즘 | 유튜브 70%, 넷플릭스 80% |
| 7 | 회의 없는 날 | 조직 규칙 | 76개 기업, 생산성 +35% |
| 8 | 모스키토 알람 | 물리 공간 · 배제 | 17.4kHz, 25세 이상 안 들림 |
| 9 | 추적 동의 팝업 | 웹 기본값 | 동의율 16~25%, 메타 손실 $10B |
| 10 | 공유 공간 | 도시 · 규칙 제거 | 사고 연 8.3건 → 1건 |

## 체험형 인터랙션

카드마다 사례를 몸으로 겪게 하는 장치가 하나씩 있다. 슬라이드에 들어오면 짧은 자동 시연이
한 번 돌고, 사용자가 조작하면 시연은 즉시 멈춘다.

| 사례 | 장치 |
|------|------|
| 장기기증 기본값 | 서식의 기본값을 토글하면 사람과 막대가 따라 움직인다 |
| 스히폴 파리 | 1분짜리 게임. 클릭으로 시작, 커서 좌우로 조준, 움직이는 파리를 맞추면 명중, 밖으로 새면 흘림. 파리는 멈춘 커서를 피한다 |
| 캠든 벤치 | 일반/캠든 벤치를 바꾸고 눕기·스케이트·낙서·숨기기·버리기를 시켜 본다 |
| 개방형 사무실 | 슬라이더로 칸막이를 내리면 대화가 끊기고 헤드폰과 메신저가 생긴다 |
| 추천 · 자동재생 | 재생 버튼 없이 저절로 시작하는 플레이어. 멈추는 데만 버튼이 필요하다 |
| 회의 없는 날 | 초대가 날아와 박히는 달력. 규칙을 켜면 수요일로 오던 초대가 튕겨 나간다 |
| 모스키토 알람 | 실제 17.4 kHz 재생, 1 kHz 확인음, 8→20 kHz 스위프와 나이별 청력 곡선 |
| 추적 동의 팝업 | 답하기 전까지 데이터가 흐른다. 답하면 100명이 따라 답하고 손실이 쌓인다 |
| 공유 공간 | 신호등 교차로와 규칙 없는 교차로 시뮬레이션. 충돌을 센다 |

## 구성상의 판단

- **반증을 숨기지 않았다.** 장기기증과 스히폴은 넛지 담론의 대표 사례지만 각각
  종단 연구로 반박되거나 원 수치가 검증된 적이 없다. 주황 세로선으로 표시했다.
- **마찰을 빼는 사례도 넣었다.** 공유 공간은 신호와 표지를 제거해 사고를 줄였다.
  환경 설계가 늘 무언가를 더하는 일은 아니다.
- **출처를 1차/2차/참고로 구분했다.** 원논문·공식 자료·당사자 인터뷰는 `1차`,
  언론 보도와 비평은 `2차`, 해설과 백과는 `참고`로 태그를 달았다.
- **규제 사례는 뺐다.** FTC Click-to-Cancel 룰이 2025년 7월 무효화되어,
  카드가 스스로를 반박하며 메시지를 잃었다.


## 보기

빌드 과정이 없다. `index.html` 하나로 완결된다.

```bash
# 바로 열기
start index.html          # Windows
open index.html           # macOS

# 또는 로컬 서버
python -m http.server 8000
```

## GitHub Pages 배포

`main`에 푸시하면 `.github/workflows/pages.yml`이 `https://gekodesignkisung.github.io/nudge-cases/`
로 배포한다. 처음 한 번은 저장소 설정이 필요하다.

1. **Settings → General → Danger Zone** 에서 저장소를 public으로 변경 (유료 플랜이면 프라이빗도 가능)
2. **Settings → Pages → Build and deployment → Source** 를 **GitHub Actions** 로 설정
3. Actions 탭에서 실패한 실행이 있으면 **Re-run**, 또는 아무 커밋이나 푸시

이 설정 전까지는 푸시마다 워크플로가 실패하지만 사이트에는 영향이 없다.

## 기술

- 빌드 없음. `index.html` 단일 파일. 외부 스크립트는 모션용 GSAP 3.12.5 (cdnjs) 하나뿐이고, 없어도 정적으로 동작한다.
- 다이어그램 전부 인라인 SVG. 인터랙션은 바닐라 JS, 소리는 Web Audio API.
- 화면 전환은 CSS `scroll-snap` + `IntersectionObserver`. 진입 모션과 체험형 장치는 GSAP.
- 다크 테마 단일. 사례 범주별 액센트 컬러 5종.
- 폰트: Bricolage Grotesque, IBM Plex Mono (Google Fonts) + 시스템 한글 글꼴

세로 공간이 부족한 경우(좁은 화면, 낮은 뷰포트)에는 해당 장 안에서만 스크롤되고,
장 사이 이동은 그대로 한 장씩 유지된다.
